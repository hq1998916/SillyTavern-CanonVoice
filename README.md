# SillyTavern-CanonVoice (原著台词库)

SillyTavern-CanonVoice 是一个用于 SillyTavern (酒馆) 的前端扩展插件。它通过调用大语言模型 (LLM)，自动从字幕文件 (`.srt` / `.ass`) 中清洗时间轴并提取原著台词，将其直接转化为 SillyTavern 的世界书 (World Info) 条目。

> **💡 说明:** 本插件的核心逻辑与代码由 AI 辅助编写完成。

## 🎯 解决的痛点 (Why use this?)

在酒馆进行影视/动漫的同人角色扮演 (RP) 时，玩家经常会遇到以下痛点：
* **剧情与台词严重 OOC**：特别是对于冷门动漫和影视作品，AI 模型自身的语料库极其稀缺，很容易出现剧情乱跑、台词完全瞎编的情况。
* **传统上下文补充方式的缺陷**：单纯在设定中补充“剧情概要”，往往缺乏具体的台词语感，AI 依然会用干瘪的通用话术回复；而开启“联网搜索”又极其容易被二创设定或无关的网络信息“污染”记忆。

**本插件的解决方案：**
直接利用原著字幕文件建立最纯正的台词场景库。当 RP 剧情推进到相应情境时，AI 能从世界书中精准读取原著台词与语境作为参考。这能在最大程度上限制 AI 放飞自我，保证剧情不乱跑、台词不瞎编。

## ✨ 特性 (Features)

* **按需指定提取**：支持从字幕中精准剥离特定角色的台词。如果“目标角色”留空，则默认提取所有说话人的台词（适用于构建群像剧本）。
* **原生扩展 API 直连**：调用 SillyTavern 原生扩展接口进行操作。无需手动导入/导出 JSON 文件，解析后直接追加至所选世界书。
* **缓冲与撤回机制**：
  * 解析后的数据会先进入可视化的缓冲池，支持在入库前手动微调。
  * 支持“撤回上一次追加”操作，撤回状态保存在浏览器 `sessionStorage` 中，刷新页面也不会丢失后悔药。
* **独立 API 引擎**：内置独立的 API 配置面板。允许为字幕解析任务配置专属的 API 端点，与主界面的 RP 聊天模型物理隔离（例如：用较便宜的模型专门跑台词处理任务）。
* **场景智能聚合**：自动识别同一场景内的连续对话，并将其合并为一个世界书条目，减少条目数量，降低 Token 开销。

## 📦 安装 (Installation)

1. 在 SillyTavern 顶部菜单栏点击 **Extensions（扩展程序）** 图标。
2. 点击 **Install Extension（安装扩展程序）**。
3. 在输入框中粘贴本仓库的地址：
   ```text
   [https://github.com/hq1998916/SillyTavern-CanonVoice](https://github.com/hq1998916/SillyTavern-CanonVoice)

4. 点击保存，等待安装完成提示。
5. 刷新页面或重启 SillyTavern。

🚀 使用流程 (Usage)

* API 配置（可选）
在 [独立 API 设置] 中填写用于解析的 URL、Key 和模型。如果留空，将默认使用酒馆当前连接的主 API。

* 填写目标信息

  目标角色：填写需要提取的角色名（留空则提取所有人）。

  集数/章节：强烈建议填写（例如：第8集）。该参数将作为生成条目的备注和核心关键字，对于后期在庞大的世界书中管理、过滤及检索特定剧情条目极有帮助。

* 解析字幕
  上传下载好的 .srt 或 .ass 文件，点击“开始让 AI 解析字幕”。结果将输出至缓冲池。

* 入库与撤回

  在下拉列表中选择目标世界书（或选择新建），点击保存到世界书。

  若发现入库有误，可点击下方弹出的“撤回”按钮安全回档。

## ⚙️ 高级 (Customization)
插件默认提供的提取 Prompt 如下：

请分析以下字幕内容。请根据剧情逻辑提取出台词，并标明场景上下文。输出格式必须为标准的 JSON 数组，包含 scene, speaker 和 line 字段。

如果你对场景的切分粒度或特定设定的提取有进一步要求，可直接在插件面板修改该 Prompt 模板。
